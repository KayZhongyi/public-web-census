减少幻觉，靠的是证据边界。

Public Web Census 不承诺模型永不出错。它做的是让原始事实先落地，让程序验证记录完整性，让人保留最终判断。

  • 公开可见与只读不自动发帖、评论、点赞或发送消息。
  • 原始数据不被覆盖翻译、分类、分析都写入独立文件。
  • 关键结论能回到来源稳定 ID、原文与链接一起保存。
  • 人掌握身份与验证账号确认、平台验证和业务判断均由人负责。

报告会结束，证据还会支持下一次判断。

开源、可本地运行、可由下一位同事继续使用。
